# Linko 收件箱 — 设计说明

[English](DESIGN.md) | 中文

本包是 Linko 的第一个可运行界面：渲染信封封面并记录决定。它不包含节点实现、
协议代码或传输层——它要么通过
[spec 0003](../../docs/specs/0003-lan-sync-and-transport.md) 中概念性的 REST
接口与本机节点通信，要么退回到固件数据并明确说明这一点。

## 数据契约

界面是两个文档的视图，除此之外不发明任何东西：

- [spec 0002](../../docs/specs/0002-message-envelope.md)——信封组成、四种署名类型，
  以及投递、已读、确认和动作是**相互独立的事实**这一规则。
- [spec 0005](../../docs/specs/0005-state-and-storage.md)——状态维度、游标作用域，
  以及持久事件与本地私有行之间的区分。

`src/model.ts` 以纯函数承载该契约。它是唯一决定事实含义的地方，且不依赖 DOM，
因此浏览器与 `scripts/smoke.mjs` 运行的是同一份代码。

## 独立性：被强制，而非被承诺

本包中不存在合并后的消息状态。详情视图并排渲染每个维度，并给出使其保持独立的
规则；`factViews` 每个维度只从各自的输入推导。

该性质是被测试的，而不是被声称的：冒烟检查把某设备标记为已读，然后验证投递、
确认和动作事实均未移动。按设备的表现状态按设备保存，因此聚合结果可以说
"2 台设备中 1 台已读"，但绝不会声称所有设备都已读。

## 决定

三种类型，持久性各不相同——这一区分正是关键：

| 类型 | 持久性 | 对动作状态的影响 |
| --- | --- | --- |
| `defer`（延后） | 本地私有行 | 无；信封保持打开 |
| `approve` / `reject` | 持久工作，排队等待节点 | 推进动作尝试 |
| `reopen`（撤销） | 补偿记录 | 使信封重新需要决定 |

撤销是追加一条记录，而不是删除记录，因此历史得以保留。当动作正在执行、已成功
或结果不确定时，撤销控件会被撤下并说明原因——越过该点之后，撤销将只是一种主张，
而不是事实。

## Fogg 行为模型

- **一次只给一个提示。** 同一时刻只有一个信封处于焦点，决定面板只提供一个主按钮，
  "Next decision →" 始终指向下一个真正需要人的条目。
- **低摩擦的安全选择。** 延后只需一次点击，没有副作用，且是私有的。批准则需要
  刻意再做一步，因为它是授予权限的那一个。
- **可见的进度。** 顶栏统计已决定、待处理和已延后的条目并绘制为进度条。延后被
  单独展示而不计入进度，因为它不是决定。

## About Face 原则

- **直接操作。** 通过点击封面本身选中信封；列表、事实与进度都对同一选择作出反应。
- **即时反馈。** 操作会同时更新列表、事实和进度，并由 live 区域播报结果。每个
  后果都用平实的语言说明，而不是靠暗示。
- **可逆操作。** 在撤销仍然属实期间提供撤销；不提供时给出原因。

## 安全姿态

- **对端界面数据是惰性的。** `surfaceRef` 与 `bodyRef` 渲染为引用标记。不抓取、
  不渲染、不执行，也不会为了绘制封面而联系正文持有者。
- **没有标记字符串汇聚点。** 本包不包含任何内联标记赋值、相邻标记插入、文档写入
  调用、`eval` 或 `Function` 构造器。每个值都通过 `textContent` 到达 DOM。
  冒烟检查会先剥离注释，再对构建产物进行断言。
- **不可信输入是被收窄的，而不是被"净化"的。** `parseEnvelope` 只复制已知字段，
  限制每个字符串的长度，并剥离控制字符与双向文本字符。包含 `<script>` 的消息
  仍然只是文本。
- **不依赖网络。** 没有 CDN、没有网络字体、没有远程资源。离线时预览渲染一致。
- 预览服务器只绑定回环地址，并拒绝逃逸出 `dist/` 的路径。

## 主题

浅色是纸与墨，色彩只留给信号：朱砂标记唯一需要决定的事项，靛青承载信息，
石绿标记已确定的内容。深色以深海军蓝为底、石墨为面，青色用于交互，琥珀色
用于提示注意。两种主题的角色一致，因此带颜色的元素总是有含义的。色彩风格
取自中国水墨设色的一般做法，未复制任何艺术家的作品。

## 运行

```sh
pnpm web:build     # tsc + 静态资源输出到 packages/web/dist
pnpm web:serve     # 在 http://127.0.0.1:4173 提供静态预览
pnpm web:preview   # 先构建，再启动服务
pnpm web:smoke     # 先构建，再断言上述性质
pnpm typecheck     # 根类型检查，包含本包
```

用 `?api=http://host:port` 指向节点；不指定也可以——收件箱会退回固件数据并
把自己标注为预览。

## 已知限制

- **本地台账保存在页面内。** 刷新会清除本地延后与撤销历史。在线时批准/拒绝会发送到节点，节点仍是持久权威。
- **没有持久游标。** 每次加载都从头同步，而不是从检查点恢复，因为原子地持久化
  一个批次及其检查点需要本包并不具备的存储。
- **CORS 是显式配置。** 本地节点会白名单预览来源；自定义主机或端口必须明确加入 UI 来源。
- 窄屏布局在列表与详情之间切换，而不是同时显示两者。
