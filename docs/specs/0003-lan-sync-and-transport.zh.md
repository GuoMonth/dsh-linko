# 0003 局域网同步与传输

[English](0003-lan-sync-and-transport.md) | 中文

状态：草案。

## 范围

本规格定义 Linko 本地节点、节点发现、投递恢复、REST 同步、WebSocket 加速和降级行为。它覆盖一对一投递，以及最多 500 人群聊所需的传输底座。

## 本地节点

每个安装实例运行一个本地 Linko 节点。节点拥有本地 SQLite 事件日志、发件箱、收件箱、回执、通知投影和 Peer 会话。CLI、Web UI 和 DeepSeek Harness 集成连接本地节点，不直接和每个 Peer 建立连接。

本地节点是 Peer，不是强制的中心服务器。它可以接受连接、主动连接、缓存加密对象并提供有范围的同步请求。部署可以使用一个或多个长期在线的 Peer 作为 mailbox，但任何 mailbox 都不是全局真相来源。

## 网络配置档

基础配置档使用普通 IP、HTTP 请求响应、HTTP keep-alive 和基于 TCP 的 WebSocket，并且不依赖特殊路由器或交换机配置。

增强配置档可以在能力协商后使用 IPv6、HTTP/2、QUIC、WebTransport 或 libp2p 传输。增强传输用于性能和可达性，必须能够回退到基础配置档。Linko 不能要求用户打开交换机特性、创建 VLAN 或修改路由器固件才能发送消息。

网络设备可以改善部署环境：IPv6 和 DNS-SD 可以减少手动地址配置；组播侦听可以减少发现噪声；VLAN 和 ACL 可以划分信任区域；QoS 可以优先处理交互流量。这些属于部署控制，不是 Linko 协议依赖。缺少或配置错误时，客户端仍然必须正确运行。

## 发现与覆盖网络

第一次发现应优先在本地链路使用 mDNS 上的 DNS-SD。节点公布稳定 Peer ID、协议版本、传输端点和短期能力摘要。mDNS 不用于广播消息正文。

如果 mDNS 不可用，或网络跨越路由边界，节点可以使用手动配对、已知 rendezvous Peer、Peer 交换或有边界的 DHT。发现、任务查询扩展和事件反熵同步是不同操作。直接消息尽量使用已知端点单播；主题同步使用经过选择的网格，并设置去重、扇出、字节、截止时间和最大跳数预算。

## REST 同步

REST 是恢复和事实来源接口。最小概念端点包括：

```text
GET  /v1/node
GET  /v1/health
GET  /v1/sync?cursor=...&wait=30
POST /v1/envelopes
GET  /v1/envelopes/{id}
GET  /v1/objects/{hash}
POST /v1/receipts
```

`POST /v1/envelopes` 必须根据信封 ID 或显式幂等键实现幂等。`/v1/sync` 返回有界事件批次和下一个游标。游标断裂、过期或协议不兼容时，进入快照加增量恢复。内容寻址对象可以独立请求，并根据哈希校验。

## WebSocket 加速

WebSocket 用于实时投递和 UI 响应，不是持久队列。会话从协议和能力握手开始，并携带最后已知游标；会话可以发送事件提示、小型事件、回执和流控信号。重连后，客户端使用 REST 同步修复所有缺口。

实现必须使用 ping/pong 或等价的存活检查、明确的关闭码、最大帧和队列大小、有界的处理中事件数量，以及带抖动的指数退避。共享网络故障后，节点不能制造重连风暴。

## 投递与反熵

发送方先将消息写入发件箱，再尝试网络投递。接收方持久化信封后才能报告 `delivered`。投递语义是至少一次；接收方按信封 ID 和内容哈希去重。回执是独立事件，不能修改原始信封。

节点交换紧凑摘要，再拉取缺失事件范围。每个作者的序号、因果元数据和签名内容哈希提供排序和审计能力，不要求全局总序。群聊不要求每个成员与其他所有成员保持连接。

## 局域网故障

实现必须处理 Wi-Fi 客户端隔离、VLAN 边界、IP 变化、重复 mDNS 记录、设备休眠、防火墙拒绝、半开 TCP、过期 Peer 广播和临时节点离线。Peer 身份在地址变化后保持稳定。本地缓存和发件箱把暂时的节点离线表现为延迟投递，而不是数据丢失。

## 验收证据

- 两个节点在普通 TCP 和无托管交换机配置的情况下可以工作。
- WebSocket 中断后，可以通过游标 REST 同步修复，并且不产生重复收件箱消息。
- mDNS 失败时可以回退到配对或配置好的 rendezvous Peer。
- 发现过程不传输消息正文。
- 测试能够在 100、1,000、10,000 和 20,000 个模拟 Peer 下测量字节数、重复数、延迟、队列深度和陈旧状态。
