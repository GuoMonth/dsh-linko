# 0006 本地认知账本与协作者推荐

[English](0006-cognitive-ledger-and-recommendations.md) | 中文

状态：P1/P2 实现基线。

## 账本

节点可以在用户选择的本地路径保存只追加 JSONL 账本。每条认知声明都包含 `author`、`subject`、`context`、`evidence`、`confidence`（0–1）、`expiry` 和 `audience`，并附带用于重放的 id 与创建时间。写入时拒绝无效行；读取时隔离跳过损坏行；过期声明不再参与当前推荐，但历史仍保留。

账本绝不保存全局信誉分。声明保持作者和范围。`recommendCollaborators` 是一次查询的投影：按 subject、context、audience 和评估时间过滤，返回查询范围内的相关度、全部支撑声明以及可读解释。界面必须同时展示证据和范围，不能把相关度当作授权。

## 信封体验

收件箱先呈现封面。正文对象在读者请求之前只是惰性引用。界面通过本地节点抓取并限制大小，以纯文本展示，再缓存到本地供离线查看。抓取失败会保留错误并提供重试；缓存正文不会产生任何操作授权。

只有用户授予权限后，新信封才可以触发浏览器通知。通知发送与投递、呈现、已读、确认和动作事实相互独立。重新连接或提示流丢失后的恢复路径是 REST 详情抓取。
